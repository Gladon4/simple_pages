# Simple Pages
![](resources/icon/page.webp)
A set of scripts to convert simple anotated Markdown files into static HTML web pages.

## Features
- Text
  - left center right positioning
  - and alignment
- ASCII text
- Images
  - Local
  - Weblinks
- Linking Pages
  - Internal
  - External
- Icons in the text
- Columns
- A simple page search

## Roadmap
- Multi language support
